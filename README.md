# Task 6 - Sales Trend Analysis Using Aggregations

## Objective
To analyze monthly revenue and order volume trends using SQL aggregation functions.

## Dataset
online_sales

### Table: orders
- order_id
- order_date
- amount
- product_id

## Tools Used
- MySQL Command Line Client

## SQL Concepts Used
- SUM()
- COUNT(DISTINCT)
- GROUP BY
- ORDER BY
- YEAR()
- MONTH()
- WHERE
- LIMIT

## Queries Performed
1. Monthly Revenue Analysis
2. Monthly Order Volume Analysis
3. Revenue and Order Volume by Month
4. Product-wise Revenue Analysis
5. Sales Analysis for a Specific Time Period
6. Top Revenue Generating Month

## Outcome
Successfully analyzed sales trends by month, calculated total revenue and order volume, identified product-wise revenue, and examined sales performance over specific time periods using SQL aggregation techniques.
